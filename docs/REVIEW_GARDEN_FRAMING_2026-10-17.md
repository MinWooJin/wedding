# 정원 구도와 잘린 나무 보정 — 적용 완료

2026-10-17. 사용자가 Claude 연결 후 결과를 다시 검토하고 직접 개선하도록 요청했다. 이번에는 그림 제작에 그치지 않고 런타임까지 수정했다.

## 확인한 문제

- 실제 앱과 [Pixel Guestbook](https://pixelguestbook.com/260829)을 브라우저에서 비교했다. 레퍼런스의 무대→꽃길 축은 참고하되, 사용자가 지적한 나무 잘림까지 그대로 따르지 않는다.
- 원본 `hub-top.png`와 `guestbook-bg.png` 자체의 수관이 위·옆 경계에서 잘렸다. 작은 배경을 넓은 잔디 위에 그리는 데스크톱에서는 사각형 절단선이 특히 눈에 띄었다.
- 런타임이352px 지도를320px 뷰로 확대했다. 모바일에서 좌우16px를 추가로 자르고 플레이어 이동을 따라 가로로 흔들렸다.
- 꽃띠가 배경 그림에만 있고 충돌/하객 예약에는 없어 사람이 꽃 위에 서거나 가로질러 걸었다.

## 적용

- 내장 imagegen으로 완전한 초록/벚꽃 나무를 생성했다. 수관·줄기·뿌리가 포함된 그림을 광장/방명록 안쪽에 다시 합성했다. 나무 영역은 왼쪽x6~86, 오른쪽x266~346, 아래끝y116이다. 나무 위에는22~24px 여백이 있다.
- 별도 `hub-top-v2.png`, `guestbook-bg-v2.png`를 만들고 manifest.files.maps로 선택한다. 기존 PNG는 전부 보존했다. 광장 y128 아래는 기존 그림과 바이트 단위로 동일해서 단상·꽃길·접합부 위치가 유지된다. 배경은 각각57/59색·불투명 RGBA다.
- 방명록 양옆/하단에4~8px의 불규칙한 잔디 여백을 두어 짧은 그림이 사각 사진처럼 끝나지 않게 했다. 우체통·인물·문 좌표는 그대로다.
- VIEW_W를352로 복원했다. 320/390/430px 폰에서도 지도 전체 폭을 표시하고 가로 카메라 범위가0으로 고정된다. 낮은 DPI의 정수 배율과 CSS/캔버스 잔디 위상 동기화는 유지한다.
- 실제 캔버스 높이를 CSS 높이×DPR로 설정했다. 논리 높이의 올림값을 다시 곱해서 생기는2px 안팎의 높이 불일치를 제거했다.
- 그려진 광장에만3/7열·6~17행의 꽃띠 충돌을 추가했다. 플레이어/하객 모두 피하며,18행 아래 교차로는 열어 둔다. 잔디 하객은 아래 광장에서 옆으로 갈라져 올라간다. 충돌 박스가 꽃띠에 걸리지 않도록 좌우 흔들림을±5px로 제한했다.
- 초기 인원의 약70%는 잔디, 나머지는9행 이후 중앙 길에 섞는다. 단상 앞은 비우고 군중20명, 추가 군중 그림/실제 메시지/모션 줄이기를 유지한다.
