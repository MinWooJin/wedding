# 광장 지도 리뷰: 레퍼런스 정밀 비교와 수정 방향 (2026-10-17, Claude)

- 레퍼런스: Pixel Guestbook 실제 서비스 `https://pixelguestbook.com/260829`, 390×844 화면(기기 픽셀 비율 2)에서 관찰.
- 비교 대상: 현재 광장(커밋 `b4281ab`), 같은 390×844 화면.
- 비교 그림: `docs/compare-reference-map-2026-10-17.png` (왼쪽 레퍼런스 배경만, 가운데 레퍼런스 하객 포함, 오른쪽 현재 화면).
- 결론 먼저: **"형편없다"의 원인은 그림 한두 장이 아니라 지도를 만드는 방식이다.**
  - 레퍼런스는 **지도 전체가 한 장의 그림**이다(위·반복·아래 세 조각). 길·꽃띠·잔디·아치·단상·화분·나무가 한 번에 그려져 서로 어울린다.
  - 우리는 32px 타일 위에 작은 오브젝트를 하나씩 올린다. 그래서 격자가 보이고, 장식이 "놓여 있다"는 느낌이 나고, 꽃띠는 가늘고, 소품(조명·버드배스·라벤더)이 흩어져 산만하다.
  - 여기에 상단 바·안내 카드·하단 버튼이 화면의 36%를 덮어 지도가 더 좁고 답답해 보인다. 레퍼런스는 둥근 메뉴 버튼 하나뿐이다.

## 1. 레퍼런스의 실제 구조 (네트워크 응답과 화면에서 확인)

| 항목 | 레퍼런스 | 비고 |
|---|---|---|
| 렌더러 | Pixi(WebGL) | 우리는 canvas 2D. 바꿀 필요 없음 |
| 배경 | 배경 프리셋 한 벌: **위 982×672, 반복 982×1494, 아래 982×1314** (webp), 표시 배율 0.4 → 화면 폭 393px에 꼭 맞음. 아래 조각은 위를 거울상으로 재사용 | 지도 길이는 반복 조각을 세로로 이어 늘린다 |
| 그림 입자 | 배경은 약 2 CSS px 크기의 굵은 픽셀감. 격자 없음 | 우리는 1.11 CSS px 입자에 32px 격자가 비침 |
| 신랑·신부 | 각자 4×3 걷기 시트, 표시 크기 약 45×95 CSS px. **단상 위에 서고 이름은 발밑** | 우리는 53×80, 이름은 머리 위 |
| 하객 | 수십 명, 길과 잔디에 겹쳐 서고 일부는 반투명. 이름은 발밑, 흰 글씨 + 어두운 외곽선 | 우리는 20명, 이름 머리 위(외곽선은 적용됨) |
| UI | 둥근 메뉴 버튼 1개(오른쪽 아래, 50px). 상단 바·카드·하단 버튼 없음 | 우리는 상단 바 70 + 카드 150 + 버튼 64 = 약 300px 덮음 |
| 말풍선 | 흰 사각 말풍선, 검은 글씨, 꼬리 | 비슷함 |

## 3. 수정 방향 (결정 필요한 큰 항목 두 가지, 나머지는 바로 진행)

### A. 광장 배경을 "한 장의 그림" 방식으로 바꾼다 (코덱스 + Claude)

- 레퍼런스와 같은 세 조각 구조로 간다. **위(아치·단상·화분·나무·길 시작) / 반복(길·꽃띠·잔디) / 아래(입구 광장)**.
- 우리 내부 해상도(352px 폭, 32px 격자)에 맞춰 그리므로 코드의 충돌 격자(`HUB_ROWS`)는 그대로 쓴다. 타일과 흩어진 장식 오브젝트는 광장에서 더 이상 그리지 않는다.
- 엔진은 이미 씬 배경 한 장(`assets.maps[id]`)을 지원한다. Claude가 세 조각을 세로로 이어 붙여 하나의 배경으로 합성하고, 문·표지판·케이크처럼 **눌러야 하는 것**만 오브젝트로 남긴다.
- 조각 규격과 좌표는 아래 5절(코덱스 주문)에 적었다. `docs/CODEX_PROMPT.md` 8차 요청과 같다.
- 방명록 정원도 같은 방식으로 한 장(또는 위/아래 두 조각)을 만든다. 이번 주문에는 **선택**으로 넣었다. 광장이 먼저다.

### B. 지도 위 UI를 레퍼런스처럼 비운다 (Claude)

- 상단 바(70px)와 안내 카드(150px)를 지도 위에서 치운다. 하단 버튼 3개는 **둥근 메뉴 버튼 1개 + "축하 남기기" 버튼 1개**로 줄인다.
- 두 사람 이름·D-day는 메뉴 안으로 옮기거나, 지도 위 왼쪽 위에 36px 높이의 작은 반투명 칩 하나로만 남긴다(추천: 칩 하나).
- 안내 카드 내용(공간 설명·"탭하면 이동")은 메뉴 안으로 옮기고, 처음 입장 때만 작은 토스트로 한 번 보여 준다.
- 이렇게 하면 지도가 세로 844 중 약 800px 보인다. 아치가 처음부터 전부 보이고, 하객 밀도가 같은데도 훨씬 붐벼 보인다.
- 이것은 사용자가 "모던 UI"를 원한 결정과 충돌하지 않는다. 메뉴 버튼과 팝업 카드는 지금의 모던 스타일을 유지한다. **다만 지도 위에 상시 노출되는 것을 줄이는 변화라 확인을 받고 진행하겠다.**

### C. 표시 배율과 이름표 (Claude, 바로 진행 가능)

- 화면 폭을 내부 352px이 아니라 **320px으로 채운다**(390폭에서 1.22배). 지도(352)가 화면보다 10% 넓어져 레퍼런스처럼 좌우 끝의 하객이 살짝 잘리고, 캐릭터는 59×88px로 커진다(레퍼런스 50×95).
- 카메라는 좌우로도 플레이어를 따라가되 범위를 잠근다. 데스크톱(기기 픽셀 비율 1)은 정수 배율 규칙 유지.
- 이름표를 머리 위에서 **발밑**으로 옮긴다. 레퍼런스와 같고, 사람이 겹칠 때 얼굴을 가리지 않는다.
- 분위기용 하객 수는 20명 유지. 그림이 바뀌면 길 위까지 더 채워도 어색하지 않으니 25명까지 올려 본다.

### D. 지금 당장 뺄 것 (Claude, 바로 진행 가능)

- 광장의 리본 조명·라벤더·장미 덤불·버드배스·벚꽃나무 오브젝트. 레퍼런스에 없는 산만한 요소다. 새 배경이 오기 전까지는 빈 잔디가 낫다.
- 잔디의 J/U 들꽃 타일 혼합. 격자가 더 잘 보이게 만든다. 새 배경이 오면 타일 자체를 쓰지 않는다.

## 4. 작업 순서

1. (사용자 결정) A: 배경 그림 방식 전환 승인, B: 지도 위 UI 비우기 승인.
2. Claude: C와 D를 먼저 적용한다. 그림 없이도 체감이 큰 변화다.
3. 코덱스: 8차 요청(5절) 배경 세 조각 제작. Claude의 C/D 작업과 병행 가능.
4. Claude: 세 조각 합성·충돌 격자 정렬·문/표지판 오브젝트 재배치, B 적용, 320/390/430 확인.
5. 다음: 방명록 정원 배경, 안내소·마음 전하는 곳 실내 배경도 같은 방식으로 검토.

## 5. 코덱스 8차 요청 요약

전문은 `docs/CODEX_PROMPT.md` 맨 아래 "8차 요청: 광장 배경 세 조각"에 있다. 핵심 규격:

| 조각 | 크기 | 담는 것 |
|---|---|---|
| `hub-top.png` | 352×256 (0~7행) | 종·커튼 아치(폭 200), 2단 돌계단 단상(폭 150, 윗면 y128~164), 단상에 붙은 화분 상자 한 쌍, 모서리에 걸친 둥근 초록 나무, 길 시작(y184~), 꽃띠 시작 |
| `hub-repeat.png` | 352×288 (9행) | 길(x128~224) + 꽃띠(양쪽 각 40px) + 잔디. **위아래 이음새 없음** |
| `hub-bottom.png` | 352×320 (10행) | 길이 모래 광장(1~9열)으로 넓어지며 꽃띠가 바깥으로 벌어짐. 네 문 자리(1·9열 × 19·23행)는 평평한 모래. 맨 아랫줄은 어두운 잔디 가장자리 |
| 선택 `guestbook-bg.png` | 352×448 (14행) | 방명록 정원 한 장. 우체통 자리(4~5열 × 2~4행)와 가운데 돌길(5열, 5행~)은 비워 둠 |

- 32px 격자에 정확히 맞춰 그린다. 길은 4~6열, 꽃띠는 3열·7열 안쪽 40px, 단상은 3~7열 × 4~5행.
- 1 그림 px = 1 내부 px. 레퍼런스의 굵은 입자감을 내려면 2px 단위 점묘를 써도 된다. 조각당 64색 이하.
- 레퍼런스의 구도만 따르고 그림은 새로 그린다. 레퍼런스 이미지를 복사하거나 변형하지 않는다.
