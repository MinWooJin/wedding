# 폰트와 박스 디자인 점검·수정

사용자가 지도 표지판, 정원 복귀, 소식 나누기 등을 포함한 모든 박스의 재검토를 요청했다. 검토 후 필요한 수정은 바로 반영한다는 작업 방식에 따라 적용했다.

## 발견과 결정

- Galmuri11과 Pretendard Variable은 실제 브라우저에서 정상 로딩됐다. 폰트 파일 오류보다 역할·굵기·박스 여백의 불일치가 문제였다.
- 지도 표지판은 합성 굵은 픽셀 글씨/작은 각진 사각형, 출구는 다른 크기의 사각형, 말풍선은 두꺼운 검은 테두리였다. 메뉴의 text-button에는 스타일이 없어 기본 회색 버튼이 노출됐다.
- 지도 안은 Galmuri11을 유지하고 표지판12px 보통 굵기, 말풍선14px, 이름표12px로 정리한다. 본문·입력·메뉴는 Pretendard로 읽기 쉽게 유지한다. 임의의 새 폰트는 추가하지 않는다.

## 적용

- Canvas 공통 paperBox: 아이보리 바탕, 차분한 테두리, 작은 둥근 모서리, 약한 그림자. 표지판28px/출구32px 높이와 말풍선에 같은 재질을 사용한다.
- 긴 표지판은 화면 폭 안에 제한한다. 표지판의 확대된 여백도 눌리도록 hitObject 범위를 함께 늘린다. 말풍선은 캔버스 상태를 save/restore하고 가장자리에서 꼬리도 박스 안으로 제한한다.
- DOM 카드: 아이보리 바탕과 얇은 테두리, 본문15px/줄간격1.75, 제목20px/650, 입력16px. 버튼은 최소44px, 보조 동작에도 공통 스타일과 포커스 표시를 적용한다. 카드 하단 동작은 구분선·유연한 줄바꿈으로 정리한다.
- 메뉴 타일·메시지 보기/내 위치/산책 안내·방명록 입력·안내 카드·캐릭터 선택·복사/공유 버튼이 같은 색과 간격 기준을 공유한다. HUD의 정원 복귀는 아이보리 보조 버튼, 축하 남기기는 분홍 주동작으로 구분한다.
- 소식 나누기: 제목/예식 날짜 미리보기, 읽기 전용 링크 필드, 안내문, 복사/공유/닫기 동작을 구분했다. 복사 동작을 기본 강조하고 카카오 설정이 있으면 카카오 강조를 유지한다. 실제 공유는 실행하지 않고 UI만 확인한다.
- 모달을 열 때 기존 공간 입장 토스트를 숨겨 카드 버튼을 덮지 않게 한다. 모달 안 동작의 후속 토스트는 정상 표시한다. 기존 포커스·Escape·Tab·HUD inert·통행·출구 처리는 유지한다.
- 부팅 시 두 폰트의 한글 표본을 미리 로드한다. CDN 연결이 지연되면 기존1.5초 상한 후 시스템 폰트로 진행한다.

## 검증

- npm test140개 통과. 긴 표지판 폭 제한과 말풍선의 캔버스 글씨 상태 복원을 추가 검사했다.
- 실제 화면의 지도 표지판·말풍선·메뉴·소식 나누기·방명록·정원 복귀를 확인했다.320px 방명록/390px 공유/430px 메뉴 모두 scrollWidth와 clientWidth가 같아 가로 넘침이 없었다. 입력16px·주요 버튼44px 이상을 확인했다.
- 화면 기록: `ui-boxes-menu-2026-10-17.jpg`, `ui-boxes-share-2026-10-17.jpg`, `ui-boxes-guestbook-2026-10-17.jpg`, `ui-boxes-exit-2026-10-17.jpg`.
- API/실제 갤러리 사진은 마지막 연결 방침을 유지한다.
