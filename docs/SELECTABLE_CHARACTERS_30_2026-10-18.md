# 선택 캐릭터 30종 확장 (2026-10-18)

사용자 추가 요청에 따라 선택 캐릭터를 기존10종에서30종으로 늘렸다. 과거 문서의 ‘선택10종 유지’ 지침은 이번 명시 요청으로 대체한다. 군중 전용 하객6종과 예식관 착석6종은 별도로 유지한다.

- 기존 ID0~9의 PNG·번호·색 조합을 보존했다. 기존 프로필과 방명록은 같은 모습으로 표시된다.
- 새 ID10~29는 `assets/characters/preset-10-v1.png`부터 `preset-29-v1.png`까지20장이다. 정장·원피스·한복, 다양한 머리·안경·연령대·피부색으로 구별한다. 48×72 RGBA, 이진 알파, 32색 이하, 발 기준 y72, 실제 높이60~62px다.
- 내장 **image_gen**을 에셋별로20회 호출했다. API 키는 사용하지 않았다. 최종 프롬프트·개별 설정·원본 경로는 `assets/selectable-guests-prompts.json`이다. 원본은 Git 제외 `raw/selectable-guests-source/`, 선택 보정 도구는 `.venv-assets/Scripts/python.exe tools/prepare_selectable_guests.py`다. 생성 이미지의 투명 배경 정리·최근접 축소·픽셀 정렬·팔레트 제한을 적용했고, 처음4종의 머리/몸 비율을 기존 아바타에 맞췄다. 최종 PNG는 원본 없이 사용한다.
- `assets/manifest.json`에20개 ID·버전 파일을 추가했다. 기존 맵·오브젝트·예식관 등록은 보존했다. 기존 공용 `prepare_assets.py`도30종을 인식하고 예식관 등 기존 메타데이터를 보존하도록 정리했다.
- `PRESET_COUNT`는30이다. 선택창·이미지 로더·플레이어·캐릭터 변경·프로필 검증·글쓰기 검증·광장 하객이 같은 개수를 쓴다. 새20종에는 이미지 실패 때 쓰는 개별 색 조합도 추가했다.
- 좌우 버튼은1번↔30번으로 순환한다. ‘30종 한눈에 보기’를 누르면44px 이상 터치 영역의 전체 목록을 펼치고, 선택하면 큰 미리보기로 돌아온다. 화면 폭에 따라 열 수가 줄어들며 내부 세로 스크롤로 마지막 캐릭터까지 고른다. 기존 ‘그대로 돌아가기’가 숨겨진 본인 확인 영역에 붙던 문제도 바로잡았다.

## 서버 반영 — 사용자 재배포 필요

`apps-script/Code.gs`의 허용 범위도0~29로 수정했다. **로컬 파일 수정만으로 이미 배포된 Google 웹앱은 바뀌지 않는다.** 아직 기존 서버가0~9만 받는다면 새 캐릭터의 입장·방명록 저장은 거절된다.

1. 기존 Google 스프레드시트의 Apps Script 편집기에 수정된 `apps-script/Code.gs` 전체를 붙여넣고 저장한다.
2. **배포 → 배포 관리 → 수정(연필) → 새 버전 → 배포**한다. 기존 웹앱 URL을 유지한다.
3. 사이트 변경분도 배포한 뒤 새로고침하고, 캐릭터30번으로 선택·입장·글쓰기·재방문 표시를 최종 확인한다.

이번 작업에서는 원격 push·사이트 게시·Google 웹앱 재배포를 하지 않았다. 실제 방명록에 테스트 글이나 입장 기록도 쓰지 않았다.
