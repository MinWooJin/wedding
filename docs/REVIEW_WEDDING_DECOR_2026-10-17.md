# 웨딩 장식 복원

2026-10-17. 사용자가 꽃의 단조로움과 벚꽃나무·기존 웨딩 장식 제거를 지적했고, 평가 후 복원 진행을 승인했다.

## 적용

- 기존 PNG를 삭제하거나 새 이미지로 교체하지 않았다. 새 생성 없이 보관된 그림을 게임의 Canvas 합성으로 다시 사용한다.
- `js/world/wedding-decor.js` / `decorateWeddingHub`: 광장 배경 합성 후 방명록 배경 우측의 온전한 벚꽃나무와 같은 잔디를 양 모서리에 재사용한다. 아치와 겹치는 부분은 원래 광장 그림으로 복구한다. 나무·아치·단상 위치, 전체352px 폭, 가로 카메라 고정은 유지한다.
- `aisle-flower-left/right-v2.png` 장미 장식은40×60으로 단상 아래와 꽃길 입구에 한 쌍씩, `aisle-flower-airy-left/right-v2.png` 낮은 꽃무더기는34×51로 가운데에 시차를 두고 배치한다. 모두 기존 꽃띠x88~128/x224~264 안에 있다. 길x128~224를 침범하지 않는다.
- 아래 광장에는 `party-table`, `ribbon-lantern`, `wedding-cake`를 모았다. 소품마다 원본 높이가 달라(케이크80px) 바닥을y704에 맞춘다. 하객 구역6~17행 밖이며, 네 문·표지판의 위치는 유지한다. 소품 발자국은 충돌 처리한다.
- 누락된 꽃 PNG는 해당 장식만 생략한다. 방명록 배경이 없으면 광장의 기존 나무가 남는다. 배경이 전부 없을 때의 타일 폴백도 유지한다.

## 주의

- manifest의 `hub-top-v2.png`는 바탕 그림이다. 최종 광장은 로더의 Canvas 합성을 거치므로 PNG 단독 미리보기와 다르다.
- 이전 `REVIEW_MAP`의 벚꽃·주변 장식 전부 제거 지침은 이 후속 사용자 결정으로 대체한다. 레퍼런스의 공간 구도와 정돈은 참고하되 웨딩 장식까지 없애지 않는다.
- 실제 검토는 `tools/garden-framing-review.html`의320/390/430px 앱을 이용한다. API와 실제 갤러리 사진은 계속 마지막 단계다.
