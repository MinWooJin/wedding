# 방명록 Google 시트 연결 (10분)

## 1. 시트 만들기
1. https://sheets.new 로 새 스프레드시트를 만든다. 이름은 자유(예: `웨딩 방명록`).
2. 공유 설정은 건드리지 않는다(나만 보기). 하객은 시트를 직접 보지 못한다.

## 2. 스크립트 붙여넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script**.
2. 왼쪽 `Code.gs`의 내용을 모두 지우고 이 저장소의 `apps-script/Code.gs` 내용을 붙여넣는다.
3. (선택) 맨 위 `PUBLIC_TOKEN = ''`에 아무 문자열(예: `minwoo-saeam-0109`)을 넣으면, 같은 값을 보낸 요청만 받는다. 넣었다면 4단계에서 `guestbookToken`에도 같은 값을 넣는다.
4. 💾 저장.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴 → **웹 앱**.
2. 설명: `wedding v1`, **실행 주체: 나**, **액세스 권한이 있는 사용자: 모든 사용자**.
3. **배포** → 권한 승인 창이 뜨면 본인 계정 선택 → "Google에서 확인하지 않은 앱" 화면이면 **고급 → (프로젝트 이름)(으)로 이동** → 허용.
   - 이 경고는 내가 만든 스크립트라서 나오는 것이고, 허용하는 권한은 "이 스프레드시트 읽기·쓰기"뿐이다.
4. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사한다.

## 4. 사이트에 연결
`data/config.json`에서:
```json
"guestbookApi": "https://script.google.com/macros/s/…/exec",
"guestbookToken": "",
```
`guestbookToken`은 2-3에서 `PUBLIC_TOKEN`을 넣었을 때만 같은 값으로 채운다. 저장 후 커밋·푸시하면 1~2분 뒤 사이트에 반영된다.

## 5. 확인
- 브라우저에서 웹 앱 URL을 열면 `[]`(빈 목록)이 보여야 한다.
- 사이트에서 축하 글을 남기면 시트 `guestbook` 탭에 한 줄이 생기고, 1분 안에 광장 하객·메시지 목록에 나타난다.

## 코드가 바뀌었을 때 (다시 배포)
저장소의 `apps-script/Code.gs`가 바뀌면 Apps Script 편집기에 내용을 다시 붙여넣고 저장한 뒤,
**배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**. URL은 그대로라 `config.json`은 손댈 필요가 없다.

- 2026-10-18 v2: 닉네임 중복 확인(`?action=check`), 글을 남긴 사람만 목록에 표시. 다시 배포 필요.

## 운영
- **글 숨기기:** 시트에서 그 행의 `hidden` 칸에 `TRUE`(또는 체크박스 체크)를 넣는다. 20초 안에 사라진다. 지우지 않으니 되돌릴 수 있다.
- **코드를 고친 뒤:** 배포 → 배포 관리 → 연필 → 버전 **새 버전** → 배포. URL은 그대로 유지된다(새 배포를 만들면 URL이 바뀌니 주의).
- **제한값:** `Code.gs` 위쪽 상수. 기기당 글 1분 1건·하루 10건, 입장 등록 1시간 1건, 목록 캐시 20초.
- **계정 보안:** 시트를 지키는 것은 내 Google 계정이다. 2단계 인증을 켜 둔다.
